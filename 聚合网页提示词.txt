第二步：技术难点与 Claude Code 可能会遇到的坑
当 Claude Code 开始写代码时，它可能会遇到以下问题，你可以提前知道：

API 格式不统一 (最麻烦的一点)：
DeepSeek, Kimi, 豆包, 千问：大多兼容 OpenAI 格式 (Chat Completions API)。这很好办，代码几乎一样。

浏览器并发限制：
如果你试图在前端（浏览器里）直接用 JavaScript 去请求这 5 个接口，浏览器会 blocked（因为跨域 CORS 问题和并发连接数限制）。
解决方案：必须通过你的后端服务器作为“代理”。前端只跟你的服务器说话，你的服务器去跟 5 个大模型说话。
流式输出 (Streaming)：
为了体验好，不能等 AI 写完 1000 字再显示。
后端需要设置 stream: true，然后把数据切成小块（chunk）通过 SSE 推送给前端。Claude Code 写这个逻辑非常熟练。
